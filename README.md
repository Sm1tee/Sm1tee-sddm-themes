## ⚡ Главная фишка: Установка только одной темы (без скачивания всего набора)

> 💡 **Экономьте интернет-трафик и место на диске!**  
> Полный репозиторий с **59 темами** и 60 FPS видео-обоями весит **более 1 ГБ**.  
> Если вам приглянулась конкретная тема (например, `dark_knight_storm` или `jinwoo_monarch`), вам **не нужно скачивать все видео**! Вы можете загрузить **только одну тему** — размер загрузки составит всего **~20–30 МБ**!

Выберите удобный вариант установки:

### 🔹 Вариант А: Интерактивный авто-установщик (в 1 команду)

Скрипт сам спросит, какую тему загрузить, использует технологию Git Sparse Checkout и всё настроит автоматически:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Sm1tee/sddm-theme/main/install.sh)
```

В появившемся меню:
1. Выберите пункт: `2) Быстрая установка (только одна выбранная тема)`
2. Введите номер понравившейся темы из наглядного списка на экране.

---

### 🔹 Вариант Б: Ручная загрузка 1 темы (Git Sparse Checkout)

Если вы хотите выполнить установку вручную в консоли:

```bash
# 1. Скачиваем репозиторий без тяжёлых файлов фонов
git clone --filter=blob:none --sparse https://github.com/Sm1tee/sddm-theme.git
cd sddm-theme

# 2. Укажите ID желаемой темы из галереи ниже (например: dark_knight_storm, itachi, cliffside)
export THEME="dark_knight_storm"

# 3. Скачиваем движок и файлы ТОЛЬКО выбранной темы
git sparse-checkout set --no-cone   "/README.md"   "themes/sm1tee/components/"   "themes/sm1tee/fonts/"   "themes/sm1tee/icons/"   "/themes/sm1tee/Main.qml"   "/themes/sm1tee/metadata.desktop"   "/themes/sm1tee/qmldir"   "/themes/sm1tee/configs/${THEME}.conf"   "/themes/sm1tee/backgrounds/${THEME}.mp4"   "/themes/sm1tee/backgrounds/${THEME}.png"

# 4. Копируем тему и шрифты в систему
sudo cp -r themes/sm1tee /usr/share/sddm/themes/
sudo cp -r themes/sm1tee/fonts/* /usr/share/fonts/
sudo fc-cache -fv

# 5. Активируем выбранную тему одной командой
sudo sed -i "s|^ConfigFile=.*|ConfigFile=configs/${THEME}.conf|" /usr/share/sddm/themes/sm1tee/metadata.desktop
```

## 📥 Ручная установка (всех тем)

Если вы хотите скачать весь репозиторий со всеми 59 темами:

```bash
# 1. Клонируем полный репозиторий
git clone https://github.com/Sm1tee/sddm-theme.git
cd sddm-theme

# 2. Устанавливаем файлы темы в систему
sudo cp -r themes/sm1tee /usr/share/sddm/themes/

# 3. Устанавливаем шрифты
sudo cp -r themes/sm1tee/fonts/* /usr/share/fonts/
sudo fc-cache -fv

# 4. Настраиваем SDDM конфигурацию (см. следующий раздел)
```

## ⚙️ Настройка конфигурации SDDM

Чтобы SDDM использовал тему `sm1tee`, отредактируйте файл `/etc/sddm.conf` (или создайте `/etc/sddm.conf.d/theme.conf`):

```bash
sudo nano /etc/sddm.conf
```

Внесите следующие параметры:

```ini
[Theme]
# Устанавливаем тему sm1tee
Current=sm1tee

[General]
# Включаем виртуальную клавиатуру и пути импорта компонентов темы
InputMethod=qtvirtualkeyboard
GreeterEnvironment=QML2_IMPORT_PATH=/usr/share/sddm/themes/sm1tee/components/,QT_IM_MODULE=qtvirtualkeyboard
```

## 🔄 Быстрое переключение дизайнов

Чтобы сменить тему на любую из **59 доступных**:

### Способ 1: Одной командой через терминал
```bash
# Замените 'jinwoo_monarch' на любую тему из таблицы
sudo sed -i "s|^ConfigFile=.*|ConfigFile=configs/jinwoo_monarch.conf|" /usr/share/sddm/themes/sm1tee/metadata.desktop
```

### Способ 2: Через текстовый редактор
```bash
sudo nano /usr/share/sddm/themes/sm1tee/metadata.desktop
```
Измените строку `ConfigFile=`:
```ini
ConfigFile=configs/dark_knight_storm.conf
```
*(В подвале файла `metadata.desktop` приведены все 59 вариантов — достаточно раскомментировать нужный).*

## 👤 Установка пользовательского аватара

Тема автоматически подхватывает аватар пользователя. Чтобы установить аватарку:

### Автоматически через ImageMagick:
```bash
# Замените /путь/к/вашему/фото.jpg на реальный путь к картинке
magick /путь/к/вашему/фото.jpg -auto-orient -resize '512x512^' -gravity center -extent 512x512 PNG32:"$HOME/.face.icon"
chmod 644 "$HOME/.face.icon"
```

Если ваш дистрибутив использует `AccountsService` (Ubuntu, Fedora, Arch с GNOME/KDE):
```bash
sudo install -m 644 "$HOME/.face.icon" "/var/lib/AccountsService/icons/$USER"
```

## ❓ Решение проблем (FAQ)

<details>
<summary><strong>🎥 Видео-фон черный или не проигрывается</strong></summary>

1. Убедитесь, что установлены мультимедиа-кодеки:
   - **Arch**: `sudo pacman -S qt6-multimedia-ffmpeg`
   - **Fedora**: `sudo dnf install qt6-qtmultimedia`
   - **Ubuntu/Debian**: `sudo apt install qml6-module-qtmultimedia`
2. Проверьте права на чтение: `sudo chmod -R 755 /usr/share/sddm/themes/sm1tee`
</details>

<details>
<summary><strong>🔤 Шрифты отображаются стандартным системным шрифтом</strong></summary>

1. Убедитесь, что шрифты скопированы в `/usr/share/fonts/`:
   ```bash
   sudo cp -r themes/sm1tee/fonts/* /usr/share/fonts/
   sudo fc-cache -fv
   ```
</details>

<details>
<summary><strong>🌫️ Размытие фона (Blur) срезается по краям экрана</strong></summary>

В текущей версии `Main.qml` этот дефект полностью устранён благодаря механизму отрицательного оффсета марджинов фона и включению обрезки рамки (`mainFrame.clip: true`).
</details>

<details>
<summary><strong>🔑 Текст спиннера «Осуществляется вход» сливался с ником</strong></summary>

Во всех 59 конфигурациях цвет спиннера настроен в строгом соответствии с акцентным цветом темы, что обеспечивает чёткий визуальный контраст с белым логином пользователя.
</details>
